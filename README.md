# CoIn Laser Task : Save the World

PsychoPy experiment for the Continuous Inference (CoIn) study's laser task. Participants manoeuvre a shield around a circle to block radiation beams emitted from a radioactive source while auditory MMN tones play in the background. Integrates the experiment runner, offline stimulus sequence generator, and MMN tone scheduler.

Originally developed for the PEDUKS study at OHBA (Oxford) and adapted for the MIC-Lab at the University of Osnabrück.

---

## The Task

The subject manoeuvres a "shield" around a circle to catch as many radiation beams emitted from a radioactive source as possible. This requires the subject to continuously estimate the current mean of the generative distribution of beam angles and position their shield as close as possible to that mean. Beams are emitted with noise around a mean angle that changes over time, so that the subject must track these changes and adjust accordingly.

- **Shield movement:** The shield rotates around the circle. By default this uses the `F` (counter-clockwise) and `J` (clockwise) keys on the keyboard, but a response box or other input device can be configured.
- **Shield size:** Can be fixed (default: 20° angular half-width) or participant-adjustable (e.g. 10°/20°/30°). Configurable per study via presets.
- **Sources:** The default design uses two different radioactive source images (red and blue) which differ only in their volatility - i.e., how often the generative mean of the beam distribution changes over time. One source is *stable* (rare changes), the other is *volatile* (frequent changes). The number of sources, volatility levels, and noise levels can all be customised.
- **Reward:** Each block starts with a reward amount (e.g. £1 or €1, depending on the preset). Beams that get past the shield reduce the reward. Participants receive feedback after each block. The reward currency, loss rate, and framing (loss/win) are all configurable.

## Stimulus Sequences and Counterbalancing

The default configuration has two main blocks (4 minutes each). For every block, the sequence of beam positions is read from a block-specific CSV file. The order of these blocks is determined by a session CSV file. All of these files are pre-generated by the wizard and located in the `sequences/` folder. Block count, duration, volatility, and noise levels can all be adjusted.

The default setup uses 4 counterbalancing orders:
- **Orders 1 and 3** start with a stable block; **orders 2 and 4** start with a volatile block.
- In **orders 1 and 2**, the volatile blocks correspond to the red source image; in **orders 3 and 4**, they correspond to the blue source image (and vice versa).

At the beginning of the experiment, the experimenter is prompted (via an on-screen dialog) for the participant ID, visit number, session number, order, and framing condition. Which fields appear in the dialog is configurable. The visit number corresponds to the session in a within-subjects design.

Sequences are generated offline by the wizard:
```bash
uv run python wizard.py --generate --verify   # generate sequences and verify with plots
```

## Background MMN

During the main blocks, participants hear tones that implement a mismatch negativity (MMN) paradigm. The default is a **duration MMN**: for example, two tones at the same pitch (440 Hz) - one short (50 ms) and one long (100 ms). One serves as the standard (frequent) and the other as the deviant (occurring with ~15% probability).

In the default counterbalancing scheme:
- In **orders 1 and 2**, the long tone is the deviant; in **orders 3 and 4**, the short tone is the deviant.
- In volatile blocks, the roles of standard and deviant occasionally switch. Tone-sequence volatility corresponds to the volatility condition of the main task.

A **frequency MMN** variant is also available (`mmn_type: "frequency"` in the config). All tone parameters (frequencies, durations, volume, inter-stimulus interval) are configurable via the wizard or presets. Audio can also be disabled entirely.

## EEG/MEG Triggers

Event markers can be sent to the recording system for beam emissions, shield movements, hits/misses, and block boundaries. The trigger mode is configured during setup - **no code editing required**:

| Mode | Use case |
|---|---|
| `"dummy"` | Prints trigger events to the console. No hardware needed - use for testing or demos. |
| `"parallel"` | Writes to a parallel/LPT port. |
| `"serial"` | Writes to a serial port (e.g. BrainVision TriggerBox). |
| `"lsl"` | Pushes events via Lab Streaming Layer. |

To run without any trigger hardware, select **"dummy"** in the wizard. See [HARDWARE_TRIGGERS.md](HARDWARE_TRIGGERS.md) for port addresses, custom marker codes, and setup details.

## Quick Start

```bash
python bootstrap.py
```

Creates a virtual environment (`.venv/`), installs dependencies, and launches the interactive configuration wizard. Works on Windows, macOS, and Linux.

**Requires Python 3.10** (PsychoPy and psychtoolbox have known issues with 3.11+).

### Common commands

```bash
python bootstrap.py                            # setup venv, then launch interactive wizard
uv run python wizard.py                        # run wizard directly (skip bootstrap)
uv run python wizard.py --preset PEDUKS_default   # load a preset, configure machine only
uv run python wizard.py --generate --verify       # regenerate sequences and verify with plots
uv run python wizard.py --report                  # print current config
python bootstrap.py --reinstall               # force reinstall of dependencies
```

After configuration, start the experiment:

```bash
uv run python main.py
```

## Presets

Study-design presets are JSON snapshots committed to git. Load one with `python bootstrap.py --preset NAME`:

| Preset | Description |
|---|---|
| `PEDUKS_default` | Original PEDUKS study - fixed 20° shield, duration MMN, € currency, loss/win framing |
| `CogPsy_original` | Original Cognitive Psychology adaptation |
| `Cogpsy_Rob_Version_2026` | Adapted for Rob's MEG study - 40° shield, £ currency, round progress bar, custom instructions |

Save the current config as a new preset from the wizard's interactive menu (`p`).

├── stimgen/                   # Offline sequence generation
│   ├── laser/                 # Laser stimulus sequences
│   └── mmn/                   # Auditory MMN tone sequences

├── sequences/                 # Generated sequence CSV files (git-ignored)
├── images/                    # Visual assets

## Configuration & Customisation

- **[CONFIG_GUIDE.md](CONFIG_GUIDE.md)**: Full explanation of where to edit what (presets, machine config, sequence settings, visual style, instruction overrides).
- **[HARDWARE_TRIGGERS.md](HARDWARE_TRIGGERS.md)**: Dedicated guide for setting up EEG/MEG triggers, ports, and customizing event marker codes.

Most changes (shield size, tone parameters, block duration, reward currency, visual toggles, instruction text) are made through the wizard or by editing the preset JSON - **no code editing required**. The two exceptions that are still edited directly in `laserTask/config.py` are:

1. **`StimulusStyle`** - controls colours, sizes, positions, and fonts for all on-screen elements.
2. **`TRIGGER_CODES`** - the integer values sent to EEG/MEG hardware for each event type.
