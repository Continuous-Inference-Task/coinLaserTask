# CoIn Laser Task : Save the World

PsychoPy experiment for the Continuous Inference (CoIn) study's laser task, integrating the experiment runner, laser stimulus sequence generator, and auditory MMN tone player.

---

## Quick Start

```bash
python run.py
```

Creates a virtual environment (`stw/`), installs dependencies, and launches the interactive setup wizard. Works on Windows, macOS, and Linux.

### Common commands

```bash
python run.py                            # interactive setup menu
python run.py --preset PEDUKS_default   # load a study preset, configure machine only
python run.py --generate --verify       # regenerate sequences and verify them
python run.py --report                  # print current config
python run.py --reinstall               # force reinstall of dependencies
```

## Repository Structure

```
coin_laser_task/
├── run.py                     # Bootstrap: venv setup, dependency install, launches setup.py
├── setup.py                   # Interactive configuration wizard & sequence generator
├── main.py                    # Experiment entry point
│
├── presets/                   # Study-design presets (JSON, committed to git)
├── laserTask/                 # Experiment engine (PsychoPy)
│   ├── config.json            # Runtime config (generated by setup.py, git-ignored)
│   ├── config.py              # Schema: ExperimentConfig, StimulusStyle, TRIGGER_CODES
│   ├── experiment.py          # Trial, block, and session loop
│   ├── stimuli.py             # Visual stimulus construction
│   ├── audio.py               # MMN tone scheduler
│   ├── io.py                  # File path helpers and data saving
│   ├── reward.py              # Reward tracking and framing logic
│   ├── shield.py              # Shield size profiles and reward event definitions
│   ├── triggers.py            # Hardware trigger interface
│   └── dialog.py              # Session setup dialog
│
├── stimgen/                   # Offline sequence generation
│   ├── laser/                 # Laser stimulus sequences
│   └── mmn/                   # Auditory MMN tone sequences
│
├── sequences/                 # Generated sequence CSV files (git-ignored)
├── images/                    # Visual assets
└── data/                      # Participant output files (git-ignored)
```
