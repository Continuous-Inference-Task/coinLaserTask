# Configuration Guide

This document explains the configuration system: where values come from, where to change them, and what each setting does. You only need this when something needs adjusting beyond the normal setup wizard flow.

---

## How Configuration Works

```
presets/*.json          <- study design (committed, shared)
       |  python run.py --preset NAME
laserTask/config.json   <- runtime config (git-ignored, machine-local)
       |  get_config()
ExperimentConfig        <- in-memory object used by the experiment
```

Running `python run.py --preset NAME` copies the preset's values into `laserTask/config.json`, then prompts you for machine-specific settings (monitor, triggers). Running `python run.py` without a preset lets you configure everything manually.

Derived fields (`shield_sizes`, `keyboard_backend` when empty, `serial_port` when empty, tone duration fallbacks) are computed at load time and are **not** stored in `config.json`.

---

## Where to Edit What

### `laserTask/config.json`

The primary runtime file. Generated by `setup.py`, git-ignored. Edit via the wizard (`python run.py`) or by hand for one-off tweaks. All experiment parameters live here; see the [field reference](#field-reference) below.

### `presets/*.json`

JSON snapshots of a full configuration, committed to git and shared across machines. Load one with `python run.py --preset NAME`. Save the current config as a new preset from the interactive menu (`p`).

Preset fields that affect sequence generation require running `python run.py --generate` afterwards.

### `stimgen/laser/config.json`

Written alongside `laserTask/config.json` by `setup.py`. Controls block duration, noise/volatility presets, and jump parameters for the offline sequence generator. Edit via the wizard, not by hand.

### `laserTask/config.py`

Defines the `ExperimentConfig` dataclass: field names, types, defaults, and validation logic. Not a place to configure experiments; use `config.json` or a preset instead. Defaults here are only used when `config.json` does not exist (first run).

**The two exceptions that are still edited directly in this file are:**
1. `StimulusStyle` class: controls colours, sizes, positions, and fonts for all on-screen elements.
2. `TRIGGER_CODES` dictionary: the specific integer values sent to your EEG/MEG hardware for each event (e.g., `laser_hit`: 10). If your lab requires different marker values, edit them here.

### `config_shared.py`

Removed.  The single shared constant `SEQUENCE_ROOT = "sequences/"` now lives
inline in both ``stimgen/laser/config.py`` and ``laserTask/config.py``.
Sequence version tags have been removed — filenames no longer embed version
strings and MMN blocks are generated inline from the same config.

## Field Reference

All fields below live in `laserTask/config.json` and equivalently in preset files.

### Display

| Field | Default | Description |
|---|---|---|
| `monitor_name` | `"testMonitor"` | PsychoPy monitor centre entry |
| `fullscreen` | `true` | Fullscreen mode |
| `screen_index` | `0` | Display index (0 = primary) |
| `window_size` | `[1512, 982]` | Window size in pixels (windowed mode) |
| `target_refresh_rate` | `60` | Expected Hz; warns if screen differs |
| `target_os` | `"linux"` | `"linux"`, `"windows"`, or `"macos"` |

### Input

| Field | Default | Description |
|---|---|---|
| `key_left` | `"f"` | Counter-clockwise rotation key |
| `key_right` | `"j"` | Clockwise rotation key |
| `input_device` | `"keyboard"` | `"keyboard"` or `"response_box"` |
| `keyboard_backend` | `""` | `""` = auto; `"ptb"`, `"iohub"`, `"event"` |
| `use_legacy_key_tracking` | `true` | Original key-release behaviour |

### Triggers (Hardware Integration)

Because every lab has a different EEG/MEG recording setup, configuring triggers requires setting port addresses and sometimes modifying the python code. **See [HARDWARE_TRIGGERS.md](HARDWARE_TRIGGERS.md)** for a dedicated step-by-step guide on configuring ports and modifying the event marker codes.

| Field | Default | Description |
|---|---|---|
| `trigger_mode` | `"parallel"` | `"parallel"`, `"serial"`, `"lsl"`, `"dummy"` (prints to console) |
| `parallel_address` | `"/dev/parport0"` | Linux: `/dev/parport0`; Windows: `0x0378` |
| `serial_port` | `"/dev/ttyUSB0"` | Serial port address (e.g. `COM6` on Windows) |
| `serial_baud_rate` | `115200` | Serial baud rate |

### Shield and Reward

| Field | Default | Description |
|---|---|---|
| `fixed_shield_degrees` | `20.0` | Shield angular half-width (degrees) |
| `allow_shield_adjustment` | `false` | Let participant resize shield |
| `loss_factor` | `0.003` | Per-event monetary delta |
| `currency_symbol` | `"€"` | Displayed before reward amounts |
| `flash_feedback` | `false` | Flash bar on neutral events (hits in loss, misses in win) |

### Audio (MMN)

| Field | Default | Description |
|---|---|---|
| `enable_audio` | `true` | Play MMN tones during trials |
| `mmn_type` | `"duration"` | `"duration"` or `"frequency"` |
| `tone_freq_standard` | `440.0` | Standard tone frequency (Hz) |
| `tone_freq_deviant` | `440.0` | Deviant tone frequency (Hz) |
| `tone_duration_standard` | `0.05` | Standard tone length (s) |
| `tone_duration_deviant` | `0.1` | Deviant tone length (s) |
| `tone_volume` | `1.0` | Playback volume (0-1) |
| `tone_isi_frames` | `24` | Frames between tones (~400 ms at 60 Hz) |

### Visual

| Field | Default | Description |
|---|---|---|
| `show_earth_background` | `true` | Show Earth image behind the game circle |

### Session Structure

| Field | Default | Description |
|---|---|---|
| `enable_practice` | `true` | Run practice block before main experiment |
| `reset_reward_after_practice` | `true` | Zero reward after practice ends |
| `min_laser_duration_frames` | `6` | Minimum laser visibility; warns if sequences are shorter |

### Session Dialog

| Field | Default | Description |
|---|---|---|
| `visits` | `["1","2"]` | Visit options in session dialog |
| `sessions` | `["1"]` | Session options |
| `orders` | `["1","2","3","4"]` | Counterbalancing order options |
| `framings` | `["loss","win"]` | Framing options |
| `dialog_fields` | *(all)* | Which fields appear in the dialog |
